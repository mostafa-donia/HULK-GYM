# HULK GYM PySide6 V12

تعديلات V12:

- إصلاح ألوان كل الـ popup messages عشان تبقى Dark Mode بنص أبيض واضح.
- إصلاح سبب إن واتساب كان يفتح الرقم بس وميلصقش الرسالة:
  - تم منع أي رسالة popup من الظهور أثناء الإرسال لأنها كانت بتسرق الفوكس من Chrome.
  - تم إلغاء BlockInput أثناء الإرسال لأنه ممكن يمنع PyAutoGUI نفسه من الكتابة واللصق.
  - وقت الإرسال الماوس بيتحرك لمكان آمن أعلى الشاشة بدل ما يقفل إدخال PyAutoGUI.
  - زيادة انتظار واتساب بعد البحث عن الرقم وقبل لصق الرسالة.
- نفس منطق كود WhatsApp القديم: Chrome + WhatsApp Web + Ctrl Alt / + Search + Paste message.
- حفظ رقم المدير كما هو داخل settings.json.
- الإعدادات المحمية بالباسورد كما هي.
- زر إعادة إرسال المحدد موجود في صفحة واتساب.
- بيانات الـ 30 لاعب المثال موجودة.

## التشغيل

```bat
pip install -r requirements.txt
python app.py
```

## بناء EXE واحد

```bat
build_exe_onefile_safe.bat
```

مهم: أثناء إرسال واتساب لا تلمس الماوس أو الكيبورد لحد ما البرنامج يقول انتهى.
