HULK GYM V11 - Build Notes

Recommended for sharing as one EXE:
1) Run build_exe_onefile_safe.bat
2) Take dist\HULK_GYM.exe
3) Send it as ZIP or WhatsApp document

V11 includes data as bundled starter files.
On first run, if there is no data folder beside the EXE, the app copies starter JSON data beside the EXE and then writes normally there.

If you get PyInstaller PKG archive error on another laptop:
- rebuild with --noupx
- send as ZIP/document
- or use build_exe_onedir.bat and send the full dist\HULK_GYM folder.
